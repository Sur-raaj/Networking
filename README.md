# 📘 Networking Fundamentals Lab Manual

This repository is a **learning hub and lab manual for networking fundamentals** — designed to help learners build confidence in designing, configuring, and troubleshooting networks. It contains reproducible configurations, simulation files, practical commands, and structured examples covering core networking topics. :contentReference[oaicite:0]{index=0}

---

## 🚀 Overview

Computer networking is the backbone of modern digital communication. Whether you’re a student, self-learner, or aspiring network engineer, this repo provides hands-on practice with real-world networking configurations and labs.

This project organizes materials into practical modules that gradually introduce networking concepts and configurations.

---

## 🗂️ Repository Contents

Each folder/module presents a focused topic:

1. **1-Network Cabling** – Structured cabling basics and best practices  
2. **2-Network Commands for Testing & Troubleshooting** – Useful CLI commands for network diagnostics  
3. **3-Simulation of Networking Devices** – Sample configurations for simulators like Cisco Packet Tracer / GNS3  
4. **4-Subnet and Supernet** – Subnetting and summarization examples  
5. **5-Static and Default Routes Configuration** – Manual routing setups  
6. **6-Dynamic Routing Configurations (RIP, EIGRP, OSPF, BGP)** – Fundamentals of routing protocols  
7. **7-Switch Configuration, VLANs & Inter-VLAN Routing** – Layer 2 switching labs  
8. **8-DHCP, DNS and Web Server** – Core network services deployment  
9. **9-Wireless Network Setup and Packet Analysis** – Wireless LAN setup and basic packet capture interpretation  

> *More topics may be added over time as the repository expands.* :contentReference[oaicite:1]{index=1}
